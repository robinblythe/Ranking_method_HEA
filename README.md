## README for: Continuous predicted risks should be retained when deploying clinical prediction models

This repository houses the code for the above paper in Journal of Clinical Epidemiology. The repository is organised as follows:
- "0_ED_Data_Cleaning.R" prepares the emergency department dataset for analysis
- "1_Simulation.R" sets up and conducts the simulation component of the study using data generated by the `predictNMB` package
- "2_SERP.R" re-runs the simulations using data from the Singapore General Hospital Emergency Department
- "99_utils.R" contains the helper functions required to run the analysis.

Simulation results for generated and emergency department data are in the "sim_results.rds" and "serp_results.rds" files, respectively.
The tutorial accompanying the paper can be accessed in both .pdf and .qmd file formats.
